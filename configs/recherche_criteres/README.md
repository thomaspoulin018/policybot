# Ajouter ou modifier un critère

1. Copie un fichier YAML voisin et donne-lui un nom qui le place au bon endroit dans l'ordre alphabétique.
2. Choisis un `id` stable et unique dont la première lettre correspond à `partie`; ne renumérote jamais les ids existants.
3. Ajoute un bloc `exa` pour lancer une recherche, ou omets-le pour afficher seulement la ligne dans le rapport, puis lance `python -m pytest -q`.
